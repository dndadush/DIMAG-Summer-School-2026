Welcome to homepage for the "Geometry and Algorithms of Linear Programming" lectures, which is part of the 2026 Summer School on Summer School on Combinatorics and Algorithms (https://combialgo.dimag.kr/2026/) at KAIST.

This repository contains the lecture notes and slides in the main folder, and the exercises and colab files in respective folders. Materials will be made available as the course progresses.

The lectures are organized as follows:

- Lecture 1: Introduction to Linear Programming
- Lecture 2: The Simplex Method and Diameter of Polyhedra
- Lecture 3: Smoothed Analysis of Simplex via Circuits
- Lecture 4: Straight Line Complexity of Linear Programs
- Lecture 5: Predictor Corrector Interior Point Methods

There is also short supplementary note, containing notation & theorem statements
that will be used throughout the lectures:

- Lecture 0: Background material on Linear Algebra, Calculus and Probability.
